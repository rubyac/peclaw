# 第七阶段：评测与反馈

入口 `/evaluation`。本阶段交付可运行的工程评测工具、固定版本样本、人工反馈和八项演示回归，不表示已完成真实客户试点。生成模型仍默认未配置，评测不会自行发送新的模型请求或伪造模型分析。

## 准备与运行

1. 在当前已授权项目添加案例：企业搜索、知识检索、事实陈述对照、BP 初筛对照或报告机械质量闸。
2. 对相关与明确不相关对象作标注；未选中的对象是未标注，不能擅自作负例。高级导入可使用 JSON，契约见 `/api/v1/evaluations/definitions` 与 `examples/evaluation-labels.template.json`。
3. 填写样本来源说明、合成/授权类型和使用权确认，保存名称与版本。同一机构、项目、创建者下的同名版本不能覆盖，来源或标注变化应创建新版。确认是人工声明，系统不会自动证明法律授权或标注真实。
4. 可指定另一位当前项目编辑者评审，必须有全部原文权利；报告案例还需有该报告参与权限。可单独撤销评审访问而不改动标注版本；历史反馈保留，换人需新版本。
5. 运行固定版本，等待后台完成。案例区分 measured/blocked/failed；运行 completed 只表示执行结束，不等于效果通过。
6. 查看分母、覆盖率、来源版本及实际输出，核对授权原文。作者反馈单列，指定评审的非来源作者反馈可计入独立指标。
7. 下载 JSON 证据保留定义、来源摘要、运行记录、结构化输出、计量与反馈；每次下载重新授权，不提供公开链接。

数据集最多二十个案例、一 MiB 定义和五百个绑定来源。每数据集最多三项等待/执行中的运行；每次最多三次领取，过期租约可恢复，有权限者可重试失败或取消排队/执行中的运行。重试保留原执行者；其资格已失效时应恢复资格或由合法参与人新建运行。运行元数据保留执行者 ID，比较不同运行须控制执行者权限、数据时间和语料。

## 指标含义

| 指标 | 定义与边界 |
| --- | --- |
| P@k | 前 k 个去重结果中的相关命中数 / 请求 k；没有返回的位置不算命中。任一返回对象未标注时完整分数未知 |
| precision_on_judged | 在已标注返回对象中的命中比例；不是全体结果准确率 |
| judgment_coverage | 已标注返回对象数 / 实际返回数；无返回时未知 |
| recall_on_labeled_positives | 找到的相关标注数 / 本次提交的相关标注数；不是完整行业或全库召回率 |
| NDCG@k | 0–3 级相关性、指数增益与对数折扣；结果标注不完整或无正例时未知 |
| 文本精确匹配 | NFKC/空白规范化后比较陈述文字与分类，去重后给出 precision/recall；不是语义事实准确率 |
| 独立事实正确率 | 指定非作者评审明确核对的 fact 陈述中，正确数 / 已判断数；同时显示覆盖率与样本数 |
| 独立可用率/数字案例准确性 | 独立评审明确判断的模型输出中的比例；未评不算正确，按来源任务去重 |
| P50/P95 案例耗时 | 本次评测处理已测量案例的耗时分位数，不是排队时长或上游模型推理时长 |
| 上游用量/估算费用 | 从已完成任务的调用记录读取、按任务去重；缺少费率/用量为未知，不重复记为本次新调用 |

检索评分按去重文档排序，不是逐片段命中率；底层当前最多取五十个检索片段，再按文档去重并截 k。公共库筛选截 k，记录实际生效的筛选条件。标注可为0明确不相关、1弱相关、2相关、3高度相关，界面快捷标注使用0/3，JSON可用完整等级。

已有任务去重后的全部陈述用于逐项核对，完整结构化输出也可查看。task_id 缺失会明确 blocked：模型未配置为 MODEL_NOT_CONFIGURED，已配置但未给完成草案为 COMPLETED_TASK_REQUIRED。不会把无结果当作错误答案，也不会给不可评分的案例提交“可用”分数。

缺失反馈和空分母保持 null，在页面显示“未评测／未知”。重复案例指向同一任务不会增加独立事实样本数或上游费用；同一来源有相矛盾的人评时，矛盾项不计为正确并单列数量。对同一评审/同一案例保留追加历史，汇总采用其最新标注。

独立性按应用账号和来源作者关系判定，不自动证明自然人独立、专业能力或无利益冲突。检索金标准由样本作者声明，独立反馈不悄悄改写金标准。真实数据上的比例仅反映提交样本及标注，不能据此宣称达到PRD的90%事实正确率或70%业务可用率，更不自动宣布试点成功。

## 数据、权限与可复现性

样本和标签按创建人、机构、项目、数据类型与版本保存，固定源文档/公司/任务/报告的摘要及绑定。源材料变化后不静默更新旧集；旧结果读取和附件重放也会拒绝，应创建新版。公开库未整体冻结，新增未标注结果会降低覆盖率而非被当作负例；不能假定不同运行间全库不变。

数据集/结果只对作者和明确评审开放，读取、下载、启动、反馈及后台执行都校验当前项目/原文资格。运行额外保存实际检索命中的引用；即使某命中文档未在金标准中，其撤权也阻止旧结果读取。评审共享只开放评测所需的已有模型输出，不开放原任务的私有输入/Thesis 或任意其他任务接口。

后台领取使用持久 PostgreSQL 状态、租约/token 与次数上限。评测只使用确定性数据库/本地检索、已有结构化输出和报告规则，不新调用外部模型、不提供任意脚本/URL/SQL执行入口。评测正文和反馈不写入机构通用审计日志，只记录ID、版本、分类、状态等；反馈正文在受保护的专用记录中。

四个专用 worker 分别为 catalog-worker、knowledge-worker、agent-worker、evaluation-worker。本机另开终端运行 `uv run python -m app.evaluation_worker`，全容器自动启动。真实数据保留与备份需覆盖评测定义、输出、反馈及已有模型原文；撤权不召回已合法下载副本。

## 实际八项演示回归

在完整开发仓库、dev依赖和本地基础服务已就绪后执行：

```sh
cd services/api
uv run python -m app.evaluation.demo --output ../../test-artifacts/eight-demos
```

命令只选择固定的合成测试节点，在独立临时数据库与唯一测试文件范围内执行，不支持用户传入任意代码或作为生产HTTP能力使用。输出 `eight-demos.json`、`test-outcomes.json`、README，包含实际节点结果、退出码、耗时、源代码指纹、Python版本及证据类型。缺失/跳过/失败不算通过，旧结果文件先清除，不能复用旧通过证据。

| 演示 | 当前证据 |
| --- | --- |
| 企业发现 | 实际数据库候选与标注评分，工程回归 |
| 企业画像 | 合成提供方协议与结构化输出，非真实模型效果 |
| 私有知识与定位 | 实际PDF解析/索引/检索与页码，工程回归 |

## 优化与真实试点待办

当前已避免评测重复模型调用、重复任务费用和重复陈述样本；返回未标注覆盖率，采集真实P50/P95与失败类型，允许反馈形成下一轮可比版本。它不是生产压测或性能SLO，仍需在实际数据规模下定位瓶颈再优化。

真实试点还需要授权样本、可评分的真实模型结果、合格独立评审、反馈与统计设计。模型凭据/外网未配置、真实样本未提供的本轮，不产生真实业务通过率或客户验收结论。实际执行记录见 VALIDATION_STAGE7.md。
