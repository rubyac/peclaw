# 身份与多租户安全（阶段二）

## 身份与会话

账号由具备数据库访问权限的部署操作员通过 `app.provision` CLI 开通，没有默认账户、明文密码文件或公共注册接口。密码为 Argon2id（64 MiB、3 次、2 并行度），未知账号也验证 dummy hash，统一错误不泄露邮箱存在性。输入长度和新密码最小 12 字符在后端校验。

会话使用随机 256-bit opaque token；数据库仅保存 SHA-256 摘要、用户、期限和撤销时间。Cookie 为 HttpOnly、SameSite=Strict、Path=/；生产强制 Secure 与 HTTPS Origin。默认绝对期限 8 小时。登录轮换当前 Cookie 会话，退出撤销当前会话，改密撤销全部会话，停用账号拒绝后续请求。操作员停用/恢复也撤销旧会话。

登录由 Redis 原子计数限流，邮箱摘要维度默认 10 次/15 分钟，API 对端 500 次/15 分钟；Redis 故障拒绝登录，不绕过限流。BFF 对端由多个用户共享，不信任调用方 X-Forwarded-For。新生产代理策略需单独验证。

所有写接口（含登录）检查精确 Origin；会话写操作还要求 CSRF token，与当前 HttpOnly 会话绑定。允许来源为显式配置，禁用通配符/路径/带凭据的 URL。所有私有 API 响应禁止缓存。

## 权限矩阵

| 能力 | owner | admin | member | viewer |
| --- | --- | --- | --- | --- |
| 查看已加入的机构 | 是 | 是 | 是 | 是 |
| 管理机构成员与审计 | 是 | 是，不能管理 owner 或授予 owner | 否 | 否 |
| 创建项目 | 是 | 是 | 是 | 否 |
| 读取项目 | 必须另有项目成员资格 | 必须另有项目成员资格 | 必须另有项目成员资格 | 必须另有项目成员资格 |
| 修改项目 | 项目 manager/editor | 项目 manager/editor | 项目 manager/editor | 否，即使被赋 editor |
| 管理项目 ACL | 可管理本机构 ACL，需显式授权才可读项目 | 同左 | 仅自己为项目 manager 时 | 否 |

项目角色 manager / editor / viewer。管理员的 ACL 管理权不是隐式项目读取权：管理员可以通过明确且审计留痕的操作授予自己访问权限，这是本版本有意选择的管理策略，不是对机构管理员的绝对保密。

机构和项目标识均由后端检查；私有对象不存在或无权读取统一 404。每条项目记录归属机构；ProjectMember 的复合 FK 同时绑定同机构 Project 与 Membership，防止数据层混租。停用机构成员只影响当前机构，另一机构成员资格仍可使用。全局账号停用由操作员处理，机构管理员不能停用其他租户的全局身份。

所有者和项目管理员降级检查使用行锁，防止并发移除最后一个角色。机构或账号停用可能保留历史项目 ACL 记录，但后端每次授权都先检查有效账号和机构成员资格，不因 ACL 残留恢复访问。恢复成员是显式、可审计操作；部署操作员可在组织无有效管理员时新增 owner 救援。

## 审计与任务上下文

成功写入和相应审计位于同一事务，授权拒绝另行提交必要审计。记录机构、操作者、动作、资源、结果、时间、请求标识与角色变更元数据，不记录密码、Cookie、CSRF、正文或完整项目说明。组织管理员只读取本机构审计，登录/全局操作记录归安全域，当前由操作员在数据库查看。没有审计修改/删除 HTTP 接口；这不是对数据库管理员防篡改的承诺。

阶段二提供不可变 TaskContext 与独立 session 的后台授权 guard。只序列化可信 actor/org/project ID，执行前重新查账号、成员与项目权限，权限撤销后拒绝。接口不接受调用方任务上下文。自动化测试在独立后台线程执行并验证隔离。实际队列、任务记录和重试属于阶段五，尚未接入；未来 worker 必须从服务端持久任务记录加载上下文，不能信任用户提交的 JSON。

## 尚未覆盖的能力

当前没有私有文档、切片、下载、混合检索、缓存结果、报告导出或模型调用，不能宣称其跨租户安全已验证。后续需复用这些授权边界，补充相应攻击面测试。数据库 RLS、SSO/MFA、邀请/找回密码、生产密钥管理与防篡改审计尚未实现。

Docker 主机端口仍只绑定本机；现有基础服务使用开发账户。生产仍需 HTTPS、反向代理、最小权限 DB/S3 账户与备份恢复运维验收。保护错误信息与 TLS 校验的阶段一规则继续适用。


## 阶段三公共数据隔离

公共库写权限为独立的全局 is_data_curator，默认 false；只能由本地部署操作员授予。机构成员角色修改不接受此字段。普通机构成员不能发布来源、企业、证据、合并或导入，也不能查看公共维护审计或别人的导入任务。公共可读仅面向有效机构成员或授权维护员，不是匿名开放 API。

来源共享确认针对平台所有有效机构，非公开资料和私有项目不自动进入公共库；当前没有私有资料贡献/转换接口。合法使用范围由维护员核查并记录，不能仅凭网站可访问推定可转售。真实数据提供商与商业授权仍未确定，测试和样例全部使用合成资料。

BFF 白名单增加 catalog/companies 固定路由；不支持用户控制的代理目的地。服务端不抓取用户 URL，导入仅做本地确定性解析。XLSX 使用 defusedxml、压缩展开上限、单表/行数限制，并拒绝公式、宏与外链。原始导入数据不进入审计或异常文本，受控结果只显示行状态与错误码。后台 worker 执行前重新校验创建者的账号与维护员权限。

公共审计只读取 catalog.* 动作，不混入 project.* 等机构私有操作。合并与撤销保留原始身份和证据，不自动把不同企业的事实改写为主档案事实；来源冲突可见。阶段三测试证明上述已实现的公共库与私有项目边界，不能替代未来私有知识库、下载/导出或模型上下文安全测试。

## 阶段四私有知识

知识库使用机构资格 ∩ 项目成员 ∩ 文档 ACL；后台执行在领取和最终写索引前重查执行者权限。SQL 在取关键词/向量候选前加入相同授权过滤与当前版本限制。公共目录维护权不继承私有读取能力。未授权项目 manager 只获受限文档脱敏元数据，明确修改授权有独立审计。

原文按四级 UUID 对象路径隔离，API 不接受对象 key、不发长期签名链接，下载重新授权与校验 SHA-256。附件 nosniff/no-store，解析器不执行文件中的指令、宏、公式或外部链接；资源限制与格式拒绝见 KNOWLEDGE.md。解析子进程不是完整恶意文件隔离方案。删除立即撤回应用可访问内容，后台清理原对象；备份、S3 自有版本策略及已下载副本需另行管理。任务错误/查询审计不含正文，查询只记录摘要。

## 阶段五模型与研究任务

模型输入只由后端当前授权检索构建；任务只对发起人可见，并持续要求有效机构/项目资格和原文 ACL。创建、调用前、结果提交前与详情读取均校验，旧草案不能绕过已撤销的文档资格。明选文件需外发确认，不自动扩大到其他项目。默认没有外部模型调用；配置属于部署管理员，浏览器不能指定端点/模型/secret。

版本化系统提示词与用户角色的 evidence 分离；模型没有网络、代码、SQL 或任意工具执行权限。非 unknown 陈述要求已存在引用，fact 要求来源已核验且分类为 fact；仍不证明结论语义或数字正确。取消后迟到结果不发布。模型只走 HTTPS Gateway，禁止重定向、限制响应大小、超时和预算，无隐藏重试；错误 body、凭据、问题与正文不写审计。详见 AGENTS_WORKFLOWS.md 的残余限制与服务商数据保留边界。

## 阶段六报告和导出

报告只有作者和明确指派的另一位审核人可读，独立审核要求项目编辑角色与全部来源读取资格，不能继承机构管理或公共维护权限。创建、读取、历史快照、审核和导出均重验 org/project/document；来源版本更新、删除或摘要变化阻止旧报告，审核人降权/失去原文资格也阻止作者沿用旧批准。

正文/数字/审核人变化撤销批准，正式导出绑定修订与内容摘要并检查机械质量闸、独立确认。未核验数字不能通过正文、引用长段或自由备注通道静默进入正式文件；正规附录不自动带原文全文。文件内存生成，重放仍鉴权，没有可旁路访问的长期 URL。Markdown 转义活动标记，DOCX 仅文本；已下载副本不能追回。机械数字检测不证明语义、财务或所有自然语言数量正确，仍须人工核查。详见 REPORTS.md。

## 评测与反馈

数据集限创建者/指定评审及当前项目权限，指定评审须有所有来源权限；公共维护员不获得私有旁路。运行同时检查标注来源、实际检索返回的未标注原文、任务结果和报告当前资格/版本。撤权后旧结果和 JSON 导出同样拒绝。共享评测不扩大原报告参与权限。反馈不能伪造独立身份、结果摘要或未执行案例。

导出包含获授权的样本及输出，需按敏感文件管理；已下载副本无法远程召回。评测不接受任意代码或 HTTP 端 pytest 命令，不自动发起模型调用。使用权确认仅是提交者声明，不能替代授权核实。
