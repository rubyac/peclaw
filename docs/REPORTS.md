# 报告、关键数字与独立审核（阶段六）

入口 `/reports`。支持五类报告模板，BP 初筛补齐 PRD 所列十三组章节。可以从本人在当前项目已完成的 Agent 草案转入，也可直接创建人工填写模板；创建人工模板、编辑、审核、导出均不调用生成模型。未知信息保持未知，不以模板文字冒充 AI 分析。

## 使用流程

1. 选择机构、项目、模板及授权来源，填写报告标题；或选择本人已完成的研究草案。
2. 编辑摘要、各章节陈述与分类，并明确选择引用。填写未知、局限性；已有尽调问题可修改或删除。
3. 逐项登记关键数字：名称、类型、精确十进制值、单位、币种、期间、引用 ID 和精确原文；没有数值时留空，不能填零替代未知。
4. 指定另一位具备当前项目编辑资格及所有原文读取权限的审核人，提交当前修订。
5. 审核人逐个将数字标为已核验、冲突、拒绝或不适用，并写理由；不适用只适用于没有数字的记录。有值的记录不能借“不适用”隐藏未经核验金额。
6. 机械质量闸通过后，审核人还必须确认引用、事实分类、数字登记完整、冲突和无虚构补全五项人工检查，再批准当前修订。
7. 选择草稿或正式报告，下载 Markdown / DOCX。草稿标明“内部草稿 · 未审核”，Word 页眉重复该标记；正式导出记录当前修订、报告摘要与文件 SHA-256。

作者不能自审，普通项目管理员或公共目录维护员没有报告读取旁路。报告只有作者与明确指定审核人可见，两人均须持续具备机构、项目及原文访问权。审核资格须为项目编辑者，机构只读角色不能因报告指派获得写入/审核能力。

## 数字与质量闸

登记的 metric_type 覆盖 revenue/gross_margin/shipment_volume/capacity/market_size/financing_amount/valuation/customer_count/market_share/other。数值存储为有界的精确十进制字符串，不通过 float 舍入，不自动换算单位、比例或汇率。常见币种支持 CNY/USD/EUR/HKD/JPY，其他币种不能冒用这些代号。

数值必须真实出现在同一份引用的精确子串中，且其后单位匹配，原文中能找到明确期间和币种。`1.2亿元` 不能借登记 `1.2元` 通过。复合单位（如万片/月）保留原样，不能静默删去量纲。审核人确认后才能标记 verified；系统只核对字面关联，不能据此声称审计财务真实。

正式导出默认阻止：

- 未核验、冲突、拒绝或无有效当前审核人的关键数字。
- 引文不包含登记数值、单位、币种或期间，或引文并非来源精确子串。
- 正文数字未关联同一引用下已核验且单位一致的登记项；数字引文带有其他尚未登记核验的数值。
- 数字被放入标题、尽调问题、自由备注或局限性等未逐条引用核验的通道。
- 非 unknown 陈述没有来源、引用不在当前集合、正文标为冲突、已引用公共来源标为冲突/拒绝，以及同名指标在相同期间/单位/币种下出现不同值。
- 同一企业字段的已用公共证据出现不同来源值。
- 当前修订没有有效独立批准，或批准后的内容指纹不匹配。

年份与页码有有限的格式豁免；中文数词金额/数量保守提示人工处理，不保证覆盖所有自然语言数量、图表、范围或日期格式。表头跨片段、复杂比例和汇率不会被自动补齐。需要提供包含完整上下文的授权原文，或明确保留未知。这里不是完整会计口径校验、语义蕴含证明或自动审计。

允许正式报告保留明确标注的未知与待核实信息，但不能把未经核验的数值藏在这些文本中。正式文件的来源附录只保留定位与摘要，不自动附带未经逐项核验的原始全文片段；已核验数字的精确引文随数字登记输出。草稿可以带原文，但始终标为未审核。

## 修订、审核记录与来源变化

任何正文、标题、数字登记或审核人变更都会递增 revision，撤销旧批准。修改数字会重置该项核验；换审核人重置全部数字核验。审核过程中逐项核验也产生新修订，整体批准绑定最新修订和内容 SHA-256。后续编辑不会偷偷继承旧的正式导出资格。

提交、数字核验、批准与退回均保存不可覆盖的审核记录和当时正文/数字/引用快照。点击“查看该次审核快照”可对照历史内容；快照也按当前报告成员和原文权限重新授权，不是旧内容的免鉴权副本。

报告固定创建时的引用池、原文版本与摘要；不在编辑正文时悄悄更新来源。私有文件有新版本、删除、原文读取资格撤销，或公共引用内容/核验状态改变后，旧报告详情、历史快照和导出都会拒绝，应核对当前材料后新建报告。更换审核人不代为授权原文件，必须先在知识库明确授权。

正式导出还会检查原批准审核人当前仍有效、具有项目编辑资格并能读取全部来源。审核人停用、降为只读或失去原文资格后，作者也不能继续沿用旧批准导出。

## 导出、安全与可配置项

所有导出是经 Origin/CSRF 校验的 POST 请求。服务端在锁定报告修订后重新授权、运行质量闸、渲染，再次校验来源与审核资格后才返回附件。返回 `no-store`、`nosniff`、文件摘要与导出 ID，没有公开对象 URL、长期签名链接或无需重验的附件缓存。

Markdown 的用户正文会转义 HTML/链接等活动标记，DOCX 只写文本，不执行宏、公式或读取外部资源。Word ZIP 时间和生成属性固定，使相同修订、用途、格式的幂等重放字节一致。下载文件名仅由服务器 UUID/修订生成，不使用用户标题拼接响应头。

导出记录保存在 PostgreSQL；文件在内存中生成，不永久存储为 S3 附件。相同用户、幂等键和输入返回同一份可重建文件；格式、修订或用途改变不能复用该键。即使之前已导出，重放也必须通过当前授权与质量闸。已合法下载的副本不能由应用追回，外部分享仍需机构流程控制。删除原文件会撤销应用读取，不会自动擦除报告正文、数字或审核快照的数据库历史；这些受保护记录及备份仍需依机构保留策略处置。

`REPORT_ALLOW_DRAFT_EXPORT=true` 默认允许带标记的内部草稿，部署可设为 false。正式规则为 `strict@1.0.0`，不提供绕过未核验数字或自审的开关。模板及报告编辑内容有长度/数量上限，数字登记每份最多一百条；列表显示最近五十份、导出记录最近一百条。

## 当前边界

没有真实客户报告、财务审计或投资质量评测，本阶段测试使用合成资料与真实数据库/对象存储。生成模型仍默认未配置；人工报告流程不依赖模型。没有图表 OCR、完整表格会计提取、语义事实核验或机构正式投委会系统对接。应用批准表示指定审核人完成应用中的确认，不等同审计意见、法律批准或投资保证。

阶段七再进行授权数据集、量化评测、业务试点与完整演示；不能把阶段六的合成流程测试当成实际业务效果验收。
