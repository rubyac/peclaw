# 机构私有知识库（阶段四）

登录后进入 `/knowledge`，选择已获授权的机构与项目。上传授权文件，等待后台状态变为“已可检索”，即可查看定位片段、下载原文件、检索原文和管理版本。没有默认文档或真实企业材料。公共企业目录与私有知识使用不同模型、表和路由；私有文件不会成为公共来源。

## 文件、版本与定位

支持 PDF 文本层、DOCX、XLSX、PPTX、UTF-8/带 BOM UTF-16 TXT 和 Markdown。每份 10 MiB，可通过 KNOWLEDGE_MAX_FILE_BYTES 降低上限。扫描 PDF 返回 NO_TEXT_LAYER，需要用户先做 OCR；不内置 OCR，不支持旧二进制 Office、宏、加密文件或图片识别。XLSX 不执行公式，以原公式标记展示，不能据此声称数值已计算。

PDF 提供页码，DOCX 提供段落/表格行与章节，PPTX 提供幻灯片，XLSX 提供工作表/行/单元格，文本提供行号和 Markdown 章节。每个片段携带文档/版本/项目 ID、原文件和片段 SHA-256、单元内字符偏移及定位信息。偏移针对规范化提取文字，不是 PDF 字节或屏幕像素坐标。每片段 1000 字符，重叠 100 字符，不跨提取单元拼接。

上传使用服务端生成的对象路径，按机构、项目、文档、版本隔离。幂等键按原上传用户唯一；相同输入返回原记录，不同输入冲突。添加版本需要 expected_revision；没有覆盖原对象。默认检索只包含当前版本，当前版本处理失败时不会回退旧版本；历史版本可显式查看、定位和下载。列表当前最多展示 100 份，API 提供 offset。

## 授权

每次下载、片段、搜索和修改都先检查有效账号、当前机构资格及独立项目成员权限，再检查文档范围。`project` 范围允许项目成员读取，写入仍受机构与项目角色交集约束。`restricted` 需要显式 reader/editor 授权；即使获文档 editor，项目/机构只读角色仍不能上传或删除。

机构 owner/admin 或公共目录维护员没有隐式私有项目读取权限。实际项目 manager 可看到未授权受限文档的脱敏编号并管理 ACL，但看不到标题、文件名、片段或下载；必须明确保存授权（记录审计）后才可读取。权限表单至少保留一名当前具有项目编辑能力的文档 editor；删除项目成员会级联移除其文档授权。后续停用、撤销或降权立即影响后续请求。已合法下载的本地副本无法由应用追回。

## 本地检索与模型

使用官方 `zh_core_web_md` 3.8.0 模型、中文分词及 300 维预训练静态词向量平均和归一化，模型 ID 为 `zh_core_web_md-3.8.0-mean300-v1`。这是实际本地语义基线，不是句向量 Transformer 或生成模型。模型 wheel 在 uv.lock 中固定官方 GitHub URL 与校验摘要，镜像构建时安装，运行时不下载、不训练私有文本、不向外部服务发送资料。spaCy tokenizer 访问串行化并释放临时词汇区。

模型元数据声明模型包 MIT、所用 Explosion fastText 词向量 CC0，并列出 OntoNotes 等上游来源及其许可说明；保留安装包内元数据和 LICENSE，分发部署时核对对应条款。

关键词使用中文分词后的 PostgreSQL full-text 与转义子串匹配；语义使用 pgvector 余弦距离（阈值 0.75）。查询先在 SQL 中限制当前机构、有效项目资格、文档 ACL、非删除且已完成的当前版本，再选候选。当前采用授权范围内的精确向量排序，不使用跨租户 ANN 索引。两路各取最多 100 个候选，以 RRF 融合返回最多 50 条。未知词无向量时不伪造语义命中；hybrid 可继续给出关键词结果。

结果是原文及定位，不是自动核验的事实或投资结论。静态平均向量对长句、否定、数字和细微财务语义有限；没有相关性业务评测集，不能宣称检索质量达到试点验收。结果不包含底层 embedding、存储 key 或签名下载 URL。

## 后台任务、删除与恢复

全容器模式自动运行 `knowledge-worker`；本机模式另开终端执行：

```sh
cd services/api
uv run python -m app.knowledge_worker
```

数据库持久任务状态依次为 uploading → uploaded → validating → parsing → chunking → embedding → indexed，失败记录受控代码。使用 SKIP LOCKED、120 秒租约和 claim token；进程中断后回收过期任务，最多三次执行。有权限的编辑者可手动重试失败任务，重试以当前执行者资格重新检查；超过次数需修复后添加新版本。原文哈希不符不建立索引。

逻辑删除在事务中立即撤下全部版本片段并使所有下载/检索不可用，作废正在执行的任务 token，后台再逐版本清理 S3 对象。删除与解析竞争不会重建索引，迟到的上传会再次进入清理队列。清理最多尝试三次；失败保留 deleting/OBJECT_DELETE_FAILED，界面支持管理者重试清理。删除记录/版本元数据及审计保留，不提供应用恢复。对象存储自身的版本、外部备份和用户下载副本不属于此清理承诺，需要另外制定保留策略。

Office ZIP 限 3000 项、解压总量 50 MiB、压缩比 200；拒绝宏/DTD/实体，不执行外部链接。PDF 最多 300 页，表格最多每表 5000 行/200 列、累计 25 万单元格；提取上限 200 万字符/5000 单元/2500 片段。解析子进程有 30 秒 CPU、40 秒墙钟和 2 GiB 地址空间限制；这是资源限制，不是完整恶意文件安全沙箱。worker 容器另设 2 GiB/1 CPU 限额。正文不进入审计，查询只存 SHA-256、模式和结果数。

阶段五的 Model Gateway、通用 Agent、自动报告与外部生成模型尚未实现。
