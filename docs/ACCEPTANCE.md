# 分阶段验收

阶段一已交付，本轮实现 PRD 第 17.7 节的第六阶段。每个阶段完成代码、测试、文档和验收后，再实现后续阶段；第一阶段通过并不表示产品 V1.0 已完成。

## 阶段一验收项

- 前后端与本机/Compose 运行路径可启动。
- API liveness 成功，readiness 实际检测数据库迁移、pgvector、Redis 和文件 bucket。
- 前端通过服务端 API 调用显示真实依赖状态，并有明确错误状态。
- Alembic 升级可重复执行；一次性测试库可回退再升级。
- 单元、安全基础与真实依赖集成测试通过；前端测试、类型检查、生产构建通过。
- CI、环境模板、运行与故障排查文档具备；本地生成的密钥不进入 Git。

实际执行证据写入 VALIDATION.md；未执行项与失败项明确区分。

## 后续阶段

2. 身份与多租户：组织、用户、项目授权、审计、跨租户/项目安全测试。
3. 公共企业库：CRUD、导入、筛选、来源、证据、人工去重。
4. 私有知识：格式校验、解析、混合检索、定位引用、删除与索引清理。
5. Agent：Gateway、结构化输入输出、提示词版本、显式任务、失败重试。
6. 报告审核：关键数字、证据、冲突、人工审核与导出质量闸。
7. 试点评测：授权数据集与完整八项演示，业务与隔离测试全部通过。


## 阶段二验收项

- 登录、会话摘要存储/期限/撤销、Argon2 密码、账号停用与改密。
- 机构成员与 owner/admin/member/viewer 角色；机构切换只列授权组织。
- 项目创建、编辑、独立项目 ACL；拒绝跨租户和同租户跨项目未授权访问。
- 权限变更/撤销立即影响后续请求，机构成员停用不伤及该用户其他机构资格。
- Origin + CSRF、Redis 登录限流、请求体拒绝身份/租户注入。
- 审计按机构隔离并且不存凭据/正文；最后 owner/manager 不变量与并发 owner 降级测试。
- 背景线程独立 session 验证序列化 TaskContext、跨租户拒绝与执行前权限撤销。
- 桌面/移动浏览器完成登录、机构切换、项目创建编辑、只读授权、成员停用、审计与退出。

文档下载、报告导出、缓存与正式后台队列尚未实现，相关验收留到其实现阶段；不以本阶段的授权 guard 测试代替最终业务场景测试。实际证据见 VALIDATION_STAGE2.md。


## 阶段三验收项

- Company/别名、Product、Technology、IndustryNode、DataSource/Evidence 模型与迁移。
- 企业新建/读取/更新/归档恢复、结构化筛选、受限自然语言规则、详情和基本产业地图。
- 来源许可与共享确认、具体主张证据、未知值与来源冲突展示。
- 公共维护权限与机构角色隔离，私有项目不进入公共检索；导入任务仅发起维护员可查看。
- CSV/XLSX 真正独立后台执行，逐行结果、幂等、去重提示、失败重试、崩溃恢复。
- 人工确认合并及撤销，保留原始身份、证据、版本和变更历史；不得仅依相似名称自动合并。
- 桌面/移动浏览器真实提交文件并等待 worker、查看档案、修改与证据、合并/撤销、只读用户访问。

运行证据见 VALIDATION_STAGE3.md。没有真实 500 家企业库或商业数据授权，不把建议的试点数据规模当成已完成数量。观察清单/事件采集、私有知识与 Agent/报告仍待对应阶段。

## 阶段四验收项

- 六种真实格式校验/解析、章节页码或行号定位、有限资源解析和本地预训练语义向量。
- 版本化 S3 原文、校验摘要、幂等、乐观修订与当前版本检索。
- 机构/项目/文档 ACL 在下载、片段、检索与后台执行中生效，公共维护员无旁路。
- 数据库持久任务、租约恢复、失败重试、删除撤索引与后台原文清理、竞争测试。
- 桌面与移动界面操作上传、检索、下载、历史版本、受限授权与删除。

执行证据见 VALIDATION_STAGE4.md，使用与限制见 KNOWLEDGE.md。OCR、句向量/生成模型、业务相关性评测和阶段五 Agent 未交付。

## 阶段五验收项

- 五种明确输入/输出与固定章节的研究工作流，提示词版本及摘要。
- 统一 Gateway，真实 HTTPS JSON 协议适配，超时/错误分类，默认未配置状态。
- 数据库持久任务、幂等/次数/租约/取消 token/重试与调用记录，机构预算/并发。
- 发起人及机构/项目/文档授权在创建、执行、结果提交和读取生效；引用/来源状态校验。
- 实际后台 worker 的错误追踪、三次重试上限与桌面/手机页面。

协议通过合成提供方测试，不表示真实模型/私有业务数据效果验收。运行记录见 VALIDATION_STAGE5.md，边界与配置见 AGENTS_WORKFLOWS.md。

## 阶段六验收项

- 人工模板/Agent草案转入、BP十三章节、编辑与明确引用。
- 十类关键数字登记、单位/币种/期间/精确引文、独立核验与冲突提示。
- 未登记/未核验/冲突/数值来源不匹配触发正式质量闸，未知不补零。
- 作者/审核人隔离、修订/摘要绑定批准、修改作废、不可覆盖审核快照与当前来源权限重验。
- 有标记草稿和正式 Markdown/DOCX 附件、幂等/摘要/审计，旧附件重放不能旁路授权。
- 桌面/手机完成登记、独立审核与真实文件下载。

记录见 VALIDATION_STAGE6.md，使用和机械检查边界见 REPORTS.md。通过工程测试不代表真实财务或投资效果通过。
