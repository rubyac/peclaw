## 已实现

- Argon2id 密码、随机 opaque session、摘要存储、8 小时默认期限、登录轮换、退出与改密撤销。
- 交互式账号/机构开通及全局账号停用/恢复；无默认账号，无公共自行注册。
- 机构成员、owner/admin/member/viewer 角色；单账号多机构切换。
- 项目创建、读取、修改与独立 manager/editor/viewer ACL。
- 机构级审计，成功事务和审计一起提交，授权拒绝记录结果与请求标识。
- Origin + CSRF、Redis 限流、生产 HTTPS/Secure 配置校验、输入拒绝租户/操作者注入。
- TaskContext 序列化、独立后台线程/session 执行前重新授权的基础 guard。
- 登录、项目、机构成员、审计、账号改密五个 Web 页面；固定路径 BFF 仅转发会话与必要请求头，私有响应禁止缓存。

## 测试中修正

- 数据库环境文件路径与 pgvector 健康检查沿用阶段一修复；本轮健康检查改为读取实际 Alembic head，避免停留在 0001。
- 对角色不变量加行锁，并在获得锁后重新读取资格，防止并发角色变更使用旧身份快照。
- 用精确 Origin 与 CSRF 区分写请求；额外限制非 ASCII CSRF 头，避免常量时间比较抛错变成 500。
- 最初浏览器用例的 select 定位方式未匹配带嵌套 option 的 label；改用可访问 combobox 角色与名称，重跑完整 8 项通过。
- 机构成员停用与全局账号停用分开建模和展示，机构管理员不能改变跨租户全局身份。
